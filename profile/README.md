# Codepro

Nền tảng luyện lập trình thi đấu và chấm bài trực tuyến, gồm website và ứng dụng desktop Windows.

## Các kho mã

| Kho mã | Nội dung |
| --- | --- |
| [Codepro-Web](https://github.com/Codepro-OJ/Codepro-Web) | Giao diện web, Django API, worker và hệ thống chấm bài |
| [Codepro-Client](https://github.com/Codepro-OJ/Codepro-Client) | Ứng dụng desktop Electron, trình soạn mã và kết nối máy chủ Codepro |

## Bắt đầu

Xem README trong từng kho để cài đặt, chạy và đóng gói. Client mặc định kết nối máy chủ tại `http://127.0.0.1:8888`.

## Tham gia phát triển

- Báo lỗi web/API tại [Codepro-Web Issues](https://github.com/Codepro-OJ/Codepro-Web/issues).
- Báo lỗi ứng dụng tại [Codepro-Client Issues](https://github.com/Codepro-OJ/Codepro-Client/issues).
- Đọc [hướng dẫn đóng góp](https://github.com/Codepro-OJ/.github/blob/main/CONTRIBUTING.md) trước khi mở pull request.
